# Contributing to Shape Up AI Native

Thank you for your interest in contributing! 🎉

---

## Ways to Contribute

### 1. Share Your Experience

**Have you used Shape Up with AI agents?**

Add a case study:
- Fork this repo
- Edit `docs/case-studies.md`
- Add your story (see template in that file)
- Submit PR

### 2. Add Examples

**Shaped a project well?**

Share it:
- Create folder in `examples/your-feature/`
- Add `pitch.md` using our [template](templates/pitch-template.md)
- Submit PR

### 3. Improve Documentation

**Found something unclear?**

- Fix typos, clarify language
- Add missing context
- Suggest better examples
- Submit PR or open Issue

### 4. Translate

**Speak another language?**

We'd love translations:
- Create `docs/[language-code]/` folder
- Translate core docs
- Submit PR
- Become maintainer for that language

### 5. Build Tools

**Created a tool for Shape Up AI Native?**

- Basecamp integrations
- GitHub Action workflows
- Templates generators
- Share in Discussions or PR to `tools/` folder

## Contribution Guidelines

### Style

**Documentation:**
- Clear, concise language
- Active voice ("Create a branch" not "A branch should be created")
- Examples over abstract theory
- Practical, actionable advice

**Markdown:**
- Use headings (##, ###)
- Use lists (bullet or numbered)
- Use code blocks for examples
- Use tables for comparisons

### Content Principles

**Do:**
- ✅ Be specific ("1-2 week cycles" not "shorter cycles")
- ✅ Give examples (real or realistic)
- ✅ Explain WHY (not just WHAT)
- ✅ Keep it practical

**Don't:**
- ❌ Be vague ("should consider" → "must decide")
- ❌ Assume expertise (explain terms)
- ❌ Promote specific tools (unless in tools.md)
- ❌ Add corporate jargon

### For Case Studies

**Must include:**
- Team composition (size, roles)
- Cycle length used
- What was adapted from original Shape Up
- Measurable results (completion rate, time saved, etc.)
- Key lessons learned

**Can include:**
- Company logo (with permission)
- Quotes from team members
- Graphs/charts of metrics
- Links to tools you use

**Keep anonymized if needed** (no need to reveal proprietary info)

## PR Process

### 1. Fork & Branch

```bash
git clone https://github.com/YOUR-USERNAME/shape-up-ai-native.git
cd shape-up-ai-native
git checkout -b your-feature-name
```

### 2. Make Changes

- Edit files
- Test links work
- Check markdown renders correctly

### 3. Commit

Use clear commit messages:

```
Add case study from [Company Name]

- Added real-world example of 1-week cycles
- Included metrics: 85% completion rate
- Lessons: shaping quality matters more than speed
```

### 4. Push & PR

```bash
git push origin your-feature-name
```

Then open PR on GitHub with:
- Clear title
- Description of what you changed
- Why it's valuable

### 5. Review

- Maintainers will review
- May request changes
- Will merge when ready

- Stay on topic

**Be collaborative:**
- Credit others' ideas
- Build on existing work
- Share your learnings
