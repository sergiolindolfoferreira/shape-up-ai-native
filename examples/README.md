## Contributing Examples

Have a well-shaped project you'd like to share?

1. Create folder: `examples/your-feature-name/`
2. Add `pitch.md` (use [template](../templates/pitch-template.md))
3. (Optional) Add supporting files (sketches, data samples)
4. Submit PR

**We're especially interested in:**
- Different domains (fintech, e-commerce, dev tools, etc.)
- Different sizes (small batch, big batch)
- Edge cases you encountered
- Lessons learned

---

## How to Use These Examples

**When shaping your own project:**

1. Read through similar example
2. Notice the level of detail (rough, not pixel-perfect)
3. See how rabbit holes are addressed
4. Copy the structure, adapt the content

**Don't copy verbatim** — your project is unique. Use as inspiration.
